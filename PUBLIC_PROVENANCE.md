# Public Provenance

This repository was created as an independent, sanitized source snapshot with a new Git history. It is not a mirror of `QuJindai/agent-localwiki` and is a parallel project to `QuJindai/locowiki-android-public-ci`. Neither repository is a runtime or build dependency.

The first public baseline corresponds to Flash Recall Android 0.4.0 and excludes private history, user data, recordings, voiceprints, databases, model binaries, build outputs, and credentials.
